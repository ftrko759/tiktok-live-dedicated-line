## 为什么直播非用专线不可

平台的风控首先看IP。一个IP被成百上千个账号共用（机场节点、免费VPN基本都是这样），只要其中有人违规，同IP的账号跟着遭殃，表现就是0播放、限流，严重时直接封号。专线给的是独享的原生住宅IP——地址固定、归属地真实、只有你一个人用，在平台眼里就是当地一个普通家庭宽带用户。

卡顿则是链路问题。跨境公网要绕很多跳，晚高峰拥堵时丢包率飙升，直播间最直观的表现就是观众端画面模糊、主播端掉线重连。专线走运营商级直连链路，配合主备线路切换，高峰期也撑得住码率。

顺带交代一下成本背景：传统MPLS跨境专线月费过万、申请到开通要一到三个月，那是大企业的玩法。现在的互联网专线按月付费、线上开通，个人主播也用得起，这是最近两年这类服务能铺开的原因。
